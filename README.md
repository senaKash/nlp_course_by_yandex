# 🧠 NLP Course by Yandex

Репозиторий с практикой и решениями по курсу NLP от Яндекса, а также подготовкой к дипломной работе в области машинного обучения.

## 🚀 О проекте

Изучаю ML и NLP через практику:
- реализую модели
- разбираю алгоритмы
- провожу эксперименты с нейросетями

Фокус — понимание того, как всё работает внутри.

## 📂 Содержимое

- `Logistic_Regression+TF-IDF.ipynb` — baseline для NLP (TF-IDF + логрег)
- `homework_1.ipynb` — основы ML/NLP
- `seminar_2_week.ipynb` — задания семинара
- `homework_pytorch_week_2.ipynb` — работа с PyTorch
- `naive_quantization.ipynb` — квантизация модели (FP32 → INT8)

## 🧪 Эксперименты

- сравнение **FP32 vs INT8**
- метрики:
  - Perplexity (WikiText-2)
  - KL divergence между выходами моделей
